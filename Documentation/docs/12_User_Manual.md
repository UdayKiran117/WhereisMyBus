# Passenger guide

1. Open Where Is My Bus.
2. Tap English, తెలుగు or हिन्दी.
3. Enter the bus registration number from the bus, for example TS09AB1234.
4. Tap Search bus.
5. Read the matching bus card.

To search by route, choose From and To and tap Find buses on route. If location choices are missing, connect to the internet and tap Load locations.

If no buses appear, check the number or choose another route. If the app says you are offline, turn on mobile data or Wi-Fi and try again.

The current version shows Tracking unavailable. Live maps and arrival time are not available yet. The Driver tab explains that driver sign-in and sharing will be added later.
