# Mobile UI and UX

The MAUI foundation uses royal blue #0866F5, green #007B50 for route search, rounded cards, spacious margins, 56-unit minimum buttons, light/dark surfaces and large labels. Dark colors preserve legibility. System font scaling remains enabled.

The passenger page separates registration search from route search. It includes a language selector, origin/destination pickers, retry control, loading indicator, error/empty messages and bus cards. Driver tab explains that driver features are coming later.

Search labels and error messages are available in English, Telugu and Hindi. Navigation labels still require the complete Milestone 6 localization pass. Fonts, contrast, touch behavior, keyboard overlap, TalkBack and large font layouts must be verified on Android. No app screenshot is claimed in this package because a device render was not available.

The approved handwritten and premium screen references were not attached alongside the supplied skill file. Their incorporation into final user documentation remains pending. The XAML layout is the source of truth for this foundation.
